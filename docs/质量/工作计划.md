## 5. 长期自主工作守则

1. 断点恢复：读本文件 §2/§3 未勾选项 → 接着做。
2. 每完成一项立即勾选并 commit（工作日志与代码分开提交）。
3. 新发现 bug 立即登记 BUGFIX-LOG.md（先记录后修复，防丢失）。
4. 修复原则：先读周围代码与规格，再动手；一处改动必须核对所有调用方。
5. 截图纪律：只在断言 PASS 之后拍摄，命名=断言的场景。
6. 测试脚本放 %TEMP%\opencode\，不进仓库；产物截图进 design/。
