# 2. 两项调研的答案（摘要）

**Q1：记忆管理系统能不能直接抄 OpenCode ACP 插件？**
不能直接抄代码（TS 插件、编码对话域、栈不匹配），但其架构思想全部吸收：三层 LSM 蒸馏（T1 堆肥中间产物 → T2 主题卡 → T3 菌床快照）、摘要即历史元数据、先搜索后解压、用户资产永不压缩。结合 Letta 的 sleep-time compute 形成本 APP 的热/温/冷三层记忆架构与夜间后台任务（06 文档，D37–D41）。

**Q2：底层要不要抄一个多 Agent 协作框架？抄哪个？**
都不抄。核心洞察：Agent 菌群的增殖/融合/休眠/活性在任何框架里都不存在——生态本来就是应用侧数据逻辑；框架能给的只是多步编排，而我们的流程是静态五阶段、状态本就落库。v0.2.1 后更进一步：编排层就是 App 内一个 Kotlin 协程模块（≈500 行），纯本地运行，连服务端都不需要（07 文档，D42–D46、D54）。
