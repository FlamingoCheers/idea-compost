# Idea Compost · 思想堆肥

> 一个把碎片化思想作为「面包渣」低阻力保存，并通过动态生长的 AI「菌床」对思想进行长期发酵、连接、质疑与深化的**个人认知生态系统**。

**一句话**：想到 → 丢进去 → AI 菌群帮你把它养出新东西。

## 核心机制

```text
🍞 面包渣（随手记录）
   ↓ 选择
🦠 思想益生菌（本次认知方向，≤2）+ 🪴 菌床（长期认知生态）
   ↓
🌿 思想园丁（Meta-Agent）动态召集 Agent 菌群
   ↓ 领域菌 / 方法菌 / 创造菌 多轮发酵
🌱 堆肥产物（十节结构 Markdown + 溯源）
   ↓ 用户反馈（❤️⭐↗?）
🪴 反哺菌床（Agent 活性 / 增殖 / 融合 / 休眠）
```

## 架构（v0.2.1）

- **纯本地 Agent APP**：Agent 集群与编排（Kotlin 协程）跑在设备本地，无自有服务器
- **云端仅推理**：直连 OpenAI 兼容 API（BYO Key，加密存储）
- **数据**：Room/SQLite，Markdown 真源，全量可导出
- **不依赖任何 Agent 框架**（LangGraph/Letta/AutoGen 均不引入，见 docs 调研）
