## 1. 丢面包渣（低阻力主路径，P-01）

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant UI as 首屏输入框
    participant VM as InputVM
    participant DB as Room
    participant EMB as EmbeddingClient
    participant LLM as LLMClient

    U->>UI: 输入/粘贴/分享接收
    UI->>VM: 保存（无任何必填项）
    VM->>DB: INSERT ideas (status=raw)
    DB-->>UI: 已存 ✅（界面立即可再输入）
    par 异步任务（不阻塞保存）
        VM->>EMB: embed(content)
        EMB-->>DB: INSERT idea_embeddings
    and
        VM->>LLM: title 懒生成 (maxTokens=48)
        LLM-->>DB: UPDATE ideas.title（失败静默重试下夜）
    and
        VM->>DB: bed_events += idea_created
    end
```

> 保存路径上零 LLM/零向量调用——「丢进去就完成」是硬指标（INV-3）。

## 2. 一次标准堆肥（核心闭环，status 流转完整）

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant UI as 堆肥页
    participant ORC as 编排器
    participant LLM as LLMClient
    participant DB as Room

    U->>UI: 多选面包渣（可见内容预览）→ 选益生菌（≤2）→ 深度
    UI->>ORC: startCompost(ideaIds, probioticIds, depth)

    rect rgb(235,232,220)
    note over ORC,DB: 阶段0 预检（纯代码，0 次 LLM）
        ORC->>DB: 读 ideas 全文合计 token
        alt 超 24K 或益生菌 >2
            ORC-->>UI: 拒绝并提示精选（不静默截断）
        else 通过
            ORC->>DB: INSERT composts(pending) + compost_stages(preflight)
        end
        ORC->>DB: 组装上下文包（原文全量+益生菌卡+bed_summary+休眠菌top5+洞察top10+活跃菌索引）
    end

    rect rgb(230,238,228)
    note over ORC,DB: 阶段1 识别（园丁调用1）
        ORC->>LLM: gardener_system + S1 指令 + 上下文包
        LLM-->>ORC: {gist, tensions, premises, bed_links, suggest_depth}
        ORC->>DB: compost_stages += identify；status=running
    end

    rect rgb(230,238,228)
    note over ORC,DB: 阶段2 召集（代码配额 + 园丁微调）
        ORC->>DB: 激活池按 w(a) 排序 → 强制 70/20/10 + 反驳保证 + ε-greedy
        ORC->>LLM: S2 微调（可否决 ≤1 意外菌）
        LLM-->>ORC: {vetoes, note}
        ORC->>DB: gardener_plan 落库 + compost_stages += convoke
    end

    rect rgb(224,236,244)
    note over ORC,DB: 阶段3 发酵（3 轮 × K 菌，并行 async）
        loop 轮次（标准3轮，停止条件代码判定）
            par 同轮各菌并行
                ORC->>LLM: capability_card + 轮次指令 + 统一上下文包(+前轮)
                LLM-->>ORC: JSON{claims[citations]} → 五级管线校验
            end
            ORC->>DB: 每菌一条 compost_stages（ferment_rN）
            ORC->>ORC: 停止判定：饱和/收敛/复读(emb>0.9)/4轮上限
        end
        note right of ORC: 预算守卫全程在线：超 20 次 → 熔断跳整合
    end

    rect rgb(244,236,224)
    note over ORC,DB: 阶段4 整合（园丁，只组织不新增）
        ORC->>LLM: S4 指令 + 全部轮次输出 + tensions/premises
        LLM-->>ORC: compost_output 十节 JSON（强制反方/置信度/溯源）
        ORC->>ORC: 溯源校验：source_claims 必须存在，失败降级 open_question
        ORC->>DB: output_struct 落库 + output_note 渲染缓存
    end

    rect rgb(238,230,238)
    note over ORC,DB: 阶段5 评估反哺（园丁 1 次 + 代码事务落库）
        ORC->>LLM: S5 指令（评分必须附引用证据）
        LLM-->>ORC: nutrition_awarded[]{agent, score, evidence}
        ORC->>DB: 事务：agent_contributions 落库<br/>nutrition_buffer += score<br/>洞察入库(status=emerging)<br/>bed_events += compost_completed
        ORC-->>UI: status=awaiting_feedback → 产物阅读页
    end
```

## 4. 挂起与恢复（INV-8 / 08 §7.1 诚实挂起）

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant ORC as 编排器
    participant LLM as LLMClient
    participant DB as Room

    Note over ORC: 堆肥进行中（等待页：氧气动画+keepScreenOn）
    U->>U: 切后台/锁屏
    ORC->>LLM: 当前进行中的调用自然完成（不中断）
    ORC->>DB: status=suspended；suspend_deadline=now+7天
    ORC->>ORC: 协程取消，等待页停止

    U->>U: 回到前台（7 天内）
    ORC->>DB: SELECT compost_stages ORDER BY seq DESC LIMIT 1
    alt 最近 stage=done
        ORC->>ORC: 从下一阶段续跑
    else 最近 stage=failed/degraded
        ORC->>ORC: 仅重跑该 stage（幂等：输入=已存产物）
    else 超 7 天
        ORC-->>U: 提示已过期 → failed（保留 stages 供审计）
    end
```

## 7. 状态机汇总（composts.status）

```mermaid
stateDiagram-v2
    [*] --> pending: 预检前
    pending --> running: 预检通过
    pending --> [*]: 预检拒绝（不建记录/仅提示）
    running --> suspended: 切后台/断网/预算外失败
    suspended --> running: 回前台续跑（7 天内）
    suspended --> failed: 超期
    running --> awaiting_feedback: 整合+评估完成
    awaiting_feedback --> done: 用户阅读或首次反馈
    running --> awaiting_feedback: 评估降级跳过（产物已交付）
    done --> [*]
    failed --> [*]
```
